# FiscalLens

> Plataforma de análise e validação fiscal

🚧 **Projeto em desenvolvimento**

O FiscalLens é uma aplicação desenvolvida para organizar e validar registros fiscais e identificar possíveis inconsistências por meio de regras automatizadas.

A proposta é apoiar a análise de informações fiscais e financeiras, apresentando os pontos de atenção de forma estruturada para facilitar a tomada de decisão.

## Tecnologias

- React
- JavaScript
- Node.js
- Express
- PostgreSQL

## Funcionalidades

- Cadastro e consulta de registros fiscais
- Integração entre frontend, backend e banco de dados
- Validação automatizada de registros
- Identificação de inconsistências
- Classificação por nível de prioridade
- Análise individual dos registros
- Filtros e paginação

## Em desenvolvimento

- Análise assistida por IA
- Dashboard com dados dinâmicos
- Relatórios
- Melhorias na análise e apresentação dos resultados
